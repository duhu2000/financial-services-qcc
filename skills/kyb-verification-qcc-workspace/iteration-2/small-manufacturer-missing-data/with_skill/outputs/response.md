# 小型制造企业 KYB 参考评级处理（第 2 轮）

## 一、参考结论

本题只提供了局部风险事实，未提供企业名称与 USCC 二要素核验结果、登记状态、当前企业风险扫描及 UBO 等完整 KYB 前提。因此，不能仅凭题述材料输出一个无条件成立的 A/B/C/D 等级。

为测试评分模型，若额外确认以下前提均成立：

- 企业名称与 USCC 已唯一锚定且一致；
- 登记状态正常，当前企业风险扫描成功；
- UBO 及其他第一层红线均已核验且未命中；
- 其余已核验维度没有需要加减分的事件；

则本案例应判定为**部分评分，条件性暂定参考评级 B**。该 B 不是由罚款金额或案件金额的比例计算得出，而是来自证据缺失状态及事件评级上限。第二层总分应写“待确定性计算／未形成完整总分”。

如果上述前提没有完成，结论必须改为**“信息不足，待补充核验”**，不输出字母评级。

## 二、企业规模与数据覆盖

“小型制造企业”是题设描述，但正式规模档仍缺少最近年度营业收入、资产总额和从业／参保人数等必要字段。净资产不等同于资产总额，不能据此复核行业规模档。因此报告应列示：

- 题设规模描述：小型制造企业；
- 模型复核规模档：未知；
- 最近一期净资产：3,000 万元，报告期未提供；
- 最近完整年度营业总收入：未披露；
- 覆盖状态：在红线已完整核验的条件下为“部分评分”。

净资产仅可作为已确认不利给付义务的诉讼偿付基准，不能替代营业收入计算处罚经营影响。

## 三、处罚事项处理

| 核验项         | 原始证据                                 | 模型处理                                                               |
| -------------- | ---------------------------------------- | ---------------------------------------------------------------------- |
| 事件识别       | 行政处罚和环保处罚接口返回相同决定书文号 | 按决定书文号归并为同一事件，只保留一笔 30 万元原始罚款记录，不重复计分 |
| 处罚结果       | 仅返回“罚款”                             | 只能确认属于财产罚，不能据此识别违法性质、主营关系或资格影响           |
| 违法事实       | 未返回                                   | 写“未披露”，不得根据制造业属性或处罚机关猜测                           |
| 主营关系       | 未返回                                   | 写“待核验”，不得判断为主营条线或一般条线                               |
| 公示／履行状态 | 未返回                                   | 写“未披露”，不得推定当前有效、已履行或已撤销                           |
| 年度营收       | 未披露                                   | 处罚经营影响比不可计算；不得改用净资产、注册资本或实缴资本作为替代分母 |

评分处理：

- 相同文号去重后按一个事件强制披露。
- 因处罚性质、主营关系和营业收入均不完整，不自动计算处罚金额分，标记为“待评分”。
- 性质或主营关系不明时，事件评级最高 B。
- 若后续证据确认该处罚当前存在，则“当前普通行政／环保处罚最高 B”的上限同时适用。
- 不能把“罚款”推断为轻微处罚，也不能因为金额看似不大而降低关注程度。

## 四、裁判文书处理

案件金额 1,200 万元只是文书中的案件标示金额，不等同于本企业最终承担的给付义务。现有正文没有明确：

- 本企业最终承担的给付金额；
- 裁判是否生效；
- 是否存在上诉、再审或后续执行；
- 是否为连带责任以及责任范围；
- 已履行金额或未履行余额；
- 同一纠纷是否存在其他审级记录。

因此，该记录应列为**重点待核验案件**，但不得进入近三年不利给付义务累计，不自动扣分，也不能记作“零风险”。

即使题目同时给出了案件金额和净资产，也不得由模型自行做除法或输出任何承压比。只有正文明确本企业的最终义务，且服务端或客户侧确定性计算器完成审级去重、金额确认与比值计算后，才能落入诉讼扣分区间。

## 五、四步评级过程

### 1. 红线判定

- 已披露净资产为正数，单凭该字段不触发“所有者权益不大于零”红线。
- 处罚结果只有“罚款”，没有主营许可被吊销／撤销或责令停业整顿且未恢复的明确证据，不能触发处罚红线。
- 裁判文书未明确本企业最终义务及裁判效力，不能把案件金额当作不利给付金额，也不能据此触发诉讼承压红线。
- 其他红线仍必须由主体核验、企业风险扫描和 UBO 核验确认。

### 2. 相对化评分

- 模型基准分规则为 80 分，但本案没有形成完整可复核总分。
- 处罚金额项：待评分，不自动扣分。
- 诉讼金额项：待评分，不自动扣分。
- 题目未提供的治理、历史、财务、经营、UBO 和关联风险不得假设为零，也不得自行加减分。
- 没有服务端或客户侧确定性计算器结果，不输出处罚影响比、诉讼承压比或最终总分。

### 3. 事件评级上限

- 处罚性质或主营关系不明：最高 B；
- 红线已核验但关键财务／风险明细缺失，属于部分评分：最高 B。

因此，在前述完整核验前提成立时，条件性暂定参考评级为 B；若基础核验前提不成立，则不可评分。

### 4. 人工覆写

证据缺失不能通过人工覆写变成低风险事实。只有客户业务系统或有权审核人能够在补证后覆写，并记录覆写方向、理由、证据、人员和时间；不可评分状态不得通过覆写制造字母评级。

## 六、补证与复算清单

1. 取得处罚决定书全文、违法事实、法律依据、处罚日期、是否涉及主营许可、履行及公示状态。
2. 取得最近完整年度营业总收入及报告期；保持决定书文号去重，由确定性计算器输出处罚经营影响比。
3. 下钻裁判文书，确认企业角色、裁判主文、最终给付金额、裁判效力、责任范围、履行状态及相关审级案号。
4. 由确定性计算器完成同一纠纷去重、义务金额聚合和诉讼承压比计算；模型只引用计算结果，不自行重构。
5. 补齐主体二要素、登记状态、当前风险扫描、UBO、治理、历史、财务、经营和关联风险核验结果。

补证后根据确定性结果重新适用评分区间和事件评级上限；不得预先推定复算后的具体等级。

## 七、建议报告用语

> 本次仅基于已取得资料形成部分评分。在主体二要素、登记状态、当前风险扫描、UBO 及其他红线均已完成核验且未发现异常的前提下，条件性暂定参考评级 B。行政处罚与环保处罚记录因决定书文号相同，按同一事件归并并保留一笔 30 万元原始罚款记录；违法事实、主营关系、公示状态及最近完整年度营业收入未披露，处罚金额项待评分。另有一份案件标示金额为 1,200 万元的裁判文书，但现有正文未明确本企业最终给付金额及裁判效力，故不纳入诉讼金额评分并列为重点待核验案件。本次未自行计算处罚影响比、诉讼承压比或最终总分。补齐证据并取得服务端或客户侧确定性计算结果后，应重新评级。本评级仅为公开数据试运行参考结果，业务决策由客户业务系统及有权人员作出。
