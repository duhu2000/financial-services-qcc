# KYB 修改前基线评测

## 结论

按本次指定的旧版 SKILL 机械执行，当前只能给出**暂定 C 级**，不能形成最终评级。

暂定 C 级的推导前提是：主体真实性、登记状态、治理稳定性、UBO、当前失信/限高/股权冻结等其他项目均已核验且无异常，并且 20 万元市场监管罚款经处罚决定书确认属于当前、一般、轻微行政处罚。

推导如下：

1. 在上述其他维度全部清洁时，企业起始状态符合 A 级。
2. 近 12 个月作为被告立案 80 件，超过旧版规则的 50 件阈值，机械下调一级：A → B。旧版规则只看案件数量，没有因企业规模或裁判结果良好而豁免。
3. 20 万元普通市场监管罚款属于另一项当前行政处罚；若证据确认其为轻微处罚，按“当前轻微风险（行政处罚等）”再落入 C 级，或按处罚规则再下调一级：B → C。
4. 若处罚实际被认定为严重，旧版规则允许下调两级，评级可能进一步下降；但仅凭“普通罚款 20 万元”不能作出严重程度判断。

因此：

- **旧模型的机械结果：暂定 C 级。**
- **严格证据口径的结果：材料不足，最终等级暂缓；不得把暂定 C 级写成已核验结论。**

## 企业规模和案件结果在旧模型中的作用

年营收 50 亿元、净资产 8 亿元在旧版评级规则中**没有进入计算**。20 万元罚款约占营收 0.004%、净资产 0.025%，但这两个比例只能作为背景信息，旧版 SKILL 没有授权依据这些比例抵销或调整扣级。

同样，已经下钻的裁判文书均为撤诉、驳回原告诉请或本方胜诉，说明已核实样本未形成不利裁判结果；但旧版“被告 > 50 件”规则仍会扣一级。除非能证明下钻结果覆盖全部 80 件，否则还不能将“已下钻文书均有利”外推为“全部案件均无实质损失”。

这暴露出旧模型的主要缺陷：平台型、大型企业因交易量大自然拥有更多案件，案件数量会被直接当成风险，而企业规模、败诉结果、实际给付义务和履行状态均未参与评分。

## 缺少以下证据时不得计分或扣级

### 1. 基础评级前提

缺少下列证据时，不得先假定企业为 A 级，也不得输出最终 KYB 等级：

- 企业全称、统一社会信用代码、法定代表人三项一致性核验结果；
- 当前登记状态及成立日期；
- 当前失信、被执行、限高、限出境、股权冻结、严重违法、经营异常、破产清算等致命风险扫描结果；
- UBO/实际控制人识别结果及其个人风险扫描结果；
- 历史法定代表人、股东、注册地址等治理稳定性证据；
- 关联企业重大风险及经营活跃度证据。

### 2. “被告案件超过 50 件”扣级

缺少下列证据时，不得适用该数量阈值：

- 80 件记录均锚定到同一完整企业主体，而非同名主体；
- 企业在每件案件中的角色确为被告，且案件性质确为民事；
- 完整案件清单、统计截止日和统计期间；
- 按案号、审级、再审、执行程序和同一基础纠纷完成去重，避免一项纠纷重复计数；
- 数据检索覆盖完整，能够证明去重后案件数仍超过 50 件。

如需判断诉讼是否形成实质风险，还必须补充：

- 每件案件的裁判结果及是否生效；
- 是否存在败诉、和解给付或尚未履行义务；
- 涉案金额、实际承担金额、已履行金额及未履行余额；
- “已下钻文书”覆盖的是全部 80 件还是仅部分样本。

未覆盖的案件不得默认按胜诉处理，也不得默认按败诉处理；应标记为“结果待核验”。

### 3. 行政处罚降级

缺少下列证据时，不得决定下调一级还是两级：

- 正式行政处罚决定书及决定书文号；
- 处罚机关、处罚日期、当前公示/有效状态；
- 违法事实、法律依据和处罚种类；
- 20 万元是罚款、没收违法所得还是罚没合计；
- 是否涉及主业资质、产品安全、消费者权益、反复违法或其他重大情节；
- 是否已整改、是否申请复议或提起诉讼、处罚是否被撤销或变更；
- 是否与税务、环保等其他处罚记录属于同一决定书，避免重复扣级。

只有金额，没有违法事实和处罚性质，不足以判断严重程度；“普通”这一描述不能代替决定书证据。

### 4. 规模归一化证据

旧版模型虽不使用规模归一化，但若要按题设的营收和净资产校准风险，必须取得同一财务期间、口径一致且可追溯的财务数据，优先使用经审计报表。缺少财务期间、报表口径或审计依据时，不得计算罚款/诉讼金额占比，更不得用占比调整评级。

## 基线模型评价

本案例中，旧版模型能够识别“高频被诉”和“当前行政处罚”两个观察信号，但不能区分“平台交易规模导致的高案件量”与“真实败诉负担”，也不能判断 20 万元罚款对 50 亿元营收企业的实质影响。

因此，暂定 C 级是旧规则的可复现结果，却不是充分反映本案风险的合理结果。合理模型应将案件数量降为观察指标，以生效不利裁判、未履行义务和金额承受比率为主；行政处罚应先判断性质，再结合营收或净资产占比，并对同一处罚决定书去重。
