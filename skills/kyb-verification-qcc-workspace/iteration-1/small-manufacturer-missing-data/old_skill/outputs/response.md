# KYB 修改前基线评测

## 结论

按指定的旧版 SKILL，本案例只能给出**暂定 C 级、最终评级暂缓**。

暂定 C 级的前提是：主体真实性、登记状态、治理稳定性、UBO、当前失信/限高/股权冻结等其他维度均已核验且无异常；同一决定书文号对应的处罚经补证确认仍处于当前有效状态，且没有达到拒绝类致命风险。

参考处理过程如下：

1. 在其他必核维度全部清洁的假设下，以 A 级作为参考起点。
2. 行政处罚接口和环保处罚接口返回同一决定书文号，应先合并为**一项处罚事实**，不能因为它出现在两个接口中而重复降级。旧版 SKILL 没有明确规定跨接口去重，这一步属于必要的证据去重处理。
3. 该处罚仅披露“罚款 30 万元”，未返回违法事实、处罚依据、公示/有效状态，因此无法判断应按旧规则下调一级还是两级。若后续确认属于当前轻微处罚，旧版评级表又将“当前轻微风险（行政处罚等）”直接归入 C 级；为避免把资料不全误写成 B 级，本次保守标记为暂定 C 级，但不形成最终评级。
4. 裁判文书只有一份，不满足旧版“民事诉讼作为被告超过 50 件”的数量阈值，故该规则不触发降级。文书载明案件金额 1,200 万元，但未明确本企业最终给付金额和裁判是否生效，不能把案件金额直接当作企业负债、败诉金额或未履行余额。

因此，本次结果应写为：

- **旧模型参考结果：暂定 C 级。**
- **严格证据结论：处罚严重程度和有效状态待核验，裁判责任待核验，最终 KYB 评级暂缓。**
- **不得将同一处罚重复计分，也不得将 1,200 万元案件金额直接认定为企业损失。**

## 企业规模在旧模型中的作用

题设净资产为 3,000 万元，30 万元罚款相当于净资产的 1%，1,200 万元案件金额相当于净资产的 40%；但这两个比例只能作为风险背景，**旧版 SKILL 没有规定使用净资产或营收比例调整评级**。

最近年度营收未披露时，不应估算营收、拿注册资本代替营收，或自行构造罚款/营收、案件金额/营收比例。旧版模型会因此暴露出明显缺陷：

- 处罚严重程度仍主要依赖“根据严重程度下调 1–2 级”，但没有可复现的严重程度阈值；
- 一宗潜在金额较大的诉讼因案件数量未超过 50 件而不扣级；
- 企业规模、最终裁判结果、实际给付义务和履行状态都没有进入正式评级规则。

## 补证与计分边界

### 行政/环保处罚

在决定处罚等级前，至少需要补充：

- 完整处罚决定书及唯一决定书文号；
- 处罚机关、处罚日期、违法事实和法律依据；
- 罚款、没收违法所得及其他处罚种类；
- 是否涉及主业许可、生产安全、污染物超标、故意或重复违法；
- 当前公示/有效状态，是否已撤销、变更或复议诉讼；
- 行政处罚与环保处罚记录是否确为同一决定。

在上述信息缺失时，不得自行把“罚款”解释为轻微，也不得仅凭 30 万元金额解释为严重。若确认是同一决定书，只能作为一项事件披露和处理。

### 裁判文书

在判断诉讼实质风险前，至少需要补充：

- 企业在案件中的准确诉讼地位；
- 裁判是否已经生效，是否存在上诉、再审或后续执行程序；
- 裁判主文中本企业实际承担的给付金额；
- 是否为连带责任、责任比例及责任上限；
- 已履行金额、尚未履行余额和结案状态；
- 同一纠纷是否另有其他审级或执行案号，避免重复认定。

在这些字段缺失时，1,200 万元只能披露为“案件标示金额”，不能用于判断企业已经发生 1,200 万元损失。

### 完整 KYB 前提

题设未提供企业名称、USCC、法定代表人三项一致性结果，以及登记状态、治理稳定性、UBO、致命风险、关联企业和经营活跃度等结果。因此，暂定 C 级只用于比较旧模型的规则表现，不等同于完整 KYB 结论。

## 基线模型评价

旧版模型在本案例中存在三处关键不足：没有跨接口事件去重规则，没有处罚严重程度的可执行口径，也没有用生效裁判义务和企业承受能力替代简单案件数量阈值。

因此，暂定 C 级是保守的参考标签，不是充分、可复现的最终评级。后续模型应当对同一决定书去重；处罚先按违法性质和状态分类，再结合企业规模；诉讼则以生效不利裁判、实际给付义务和未履行余额为主，案件数量仅作为观察指标。
